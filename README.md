# Personal Portfolio Website

Responsive personal portfolio built with HTML, CSS and JavaScript.

## Features
- Home, About, Education, Skills, Projects and Contact sections
- Sticky navigation with smooth scrolling and mobile menu
- Dark / light mode (saved in localStorage)
- Typing effect, animated skill bars, scroll reveal
- Contact form with JavaScript validation
- Responsive for mobile, tablet and desktop

## Run
Open `index.html` in a browser.
